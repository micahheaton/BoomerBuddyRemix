# Deferred Integrations

Build Run 1 used no production credentials, performed no deployment, charged no customer, contacted no user, and fetched no submitted URL. Interfaces or truthful local substitutes exist where they reduce future coupling; vendor selection remains an evidence-led Run 2 decision.

## Sequencing rule

Do not integrate a vendor merely to make a local screen appear production-like. Each activation needs an accountable owner, a threat/privacy review, failure and rollback tests, a cost ceiling, and observable user value. Fraud, identity, storage, and payment adapters must remain replaceable through the existing provider-neutral boundaries.

The recommended order and stop conditions are in [Run 2 Recommendation](./15-run-2-recommendation.md). The broader buy/build logic remains in [Build, Buy, Integrate](../gauntlet-zero/29-build-buy-integrate.md).
