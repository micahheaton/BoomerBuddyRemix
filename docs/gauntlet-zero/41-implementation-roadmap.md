# Implementation Roadmap

## Build Run 1 — foundation and proof (this run)

Modular monolith; typed domain; Postgres-compatible local/test persistence; provider-neutral auth/commerce/intelligence; server authorization; audit/outbox; text and URL Check flow; history; household/Trusted Circle; orientation; public/member web; mobile foundation; HQ shell; deterministic evaluation; automated security regression. No production credentials or deployment.

## Run 2 — device and production-readiness evidence

Implement and device-test iOS Share Extension and Android Sharesheet receiver; production identity in staging; managed PostgreSQL; object storage/upload quarantine; first commercial URL-reputation adapter; encryption/KMS; deletion/export; rate limiting; queues; Playwright/device E2E; expanded golden set; older-adult usability study; security and accessibility review. Prepare, but do not launch, real commerce adapters.

## Run 3 — private family pilot

Invite-only US pilot with consented family pairs; production payments only after legal/security gates; incident/recovery content reviewed; operational support hours; feedback and false-report workflows; instrumentation and cohort definitions. Optimize activation and trust, not feature count.

## Run 4 — B2B2C pilot readiness

Sponsor eligibility and bulk entitlements, organization isolation, partner reporting with privacy thresholds, SSO/provisioning as needed, contract/DPA/security packet, pilot success plan, implementation runbook, and credit-union design partner discovery.

## Explicitly later

Image/audio/document pipelines, staffed Safety Setup, premium intelligence portfolio, marketing automation, complex CRM, adviser workflows, internationalization, and embedded/OEM distribution follow evidence and operating capacity.
