# HQ Agent Web Queue Register

Status: **partial local control plane; unavailable queues are explicit**

HQ is a bounded internal control plane. A missing queue is `unavailable`, never proof that zero work
exists. Every implemented queue must be role-scoped, content-minimized, bounded, audited where
required, and incapable of executing an external action merely because a row appears.

## Authority ladder

1. Draft only.
2. Recommend or queue an approval.
3. Bounded autonomous internal action only after code-owned policy, budget, audit, and stop controls.
4. Bounded external action only after that exact action class has independent provider/deployed
   evidence and explicit approval.

Production deploys, live money movement, credits, mass messages, promotional outreach, fraud-policy
changes, legal/terms changes, public corrections, hiring, and contracts remain approval-gated.
Discretionary intelligence and evaluation schedules are omitted from production until a reviewed
policy-authorized executor exists. Safety-critical retention and canonical transaction repair remain
separate system work.

## Remaining acceptance work

The legacy support, review, opportunity, attention, and revenue queues now have local caps and
explicit truncation signals. They still need frozen-candidate and realistic-scale evidence. The
full HQ gate still requires incident and dependency queues, deployed session/role evidence, managed
identity, real PostgreSQL concurrency, alert receipt, and human usability/accessibility review.
Local screens do not establish those facts.
