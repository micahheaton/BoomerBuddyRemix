# Strategic Value Register

## Build Run 1 reconciliation

Run 1 created a clean, testable **foundation**, not an acquisition moat. Current evidence is deliberately narrower than the long-term asset thesis:

| Foundation now present             | Evidence                                                                                                                                                                                       | Strategic limitation                                                                                                |
| ---------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| Trust-first software/IP baseline   | Separate customer/HQ audiences, tenant-scoped authorization, independent protected enrollment, provider-neutral entitlements, content-minimized Check flow, ADRs, and reproducible local tests | Much of the code is reproducible commodity engineering; it has no deployed reliability or customer validation.      |
| Consent and household data model   | Explicit pairwise consent, narrow sharing, withdrawal, allowances, and audit/outbox semantics                                                                                                  | All relationships are synthetic; no retained, consented household network exists.                                   |
| Fraud/action evaluation harness    | Versioned rules, evidence/actions, 12 synthetic fixtures, and forbidden-action assertions                                                                                                      | The corpus is project-authored, single-adjudicator, not calibrated, and not a defensible data asset yet.            |
| Partner-ready commerce abstraction | Versioned plans, source-neutral grants, sponsorship, allowances, and reconciliation state                                                                                                      | No billing provider, sponsor, contract, payment, eligibility feed, or observed economics exists.                    |
| HQ operating projection            | Separate role-scoped local views for customers, fraud, revenue, system health, and audit                                                                                                       | Metrics and pipeline are seeded/local; verified safe-action outcome instrumentation and real operations are absent. |

No recurring revenue, customer cohort, brand equity, distribution agreement, partner relationship, rights-cleared fraud corpus, verified outcome history, or founder-independent safety operation was created during Run 1. Raw submissions remain a liability rather than an asset. The next value milestone is evidence that consenting households repeatedly complete safer actions—not a larger feature count.

## Non-assets and traps

Raw sensitive submissions without clear consent/data rights are a liability, not a moat. Unvalidated AI prompts, vanity customer counts, one-off partner customizations, fabricated “loss prevented,” and dependence on a single model/vendor reduce value.

## Diligence practices to start now

Clean source/IP ownership; dependency licensing/SBOM; documented architecture decisions; reproducible builds/tests; metric definitions; provider and consent provenance; security/audit history; customer and partner contract indexing; revenue reconciliation; retention/deletion enforcement; evaluation versioning; and an honest incident register.

## Acquisition thesis

Likely strategic categories include identity/cybersecurity, telecommunications, financial institutions, insurers, caregiver/senior platforms, and consumer trust vendors. The thesis remains a hypothesis: build an independent business whose data rights, quality evidence, relationships, and recurring economics are useful across categories rather than tailoring the company to one imagined acquirer.
